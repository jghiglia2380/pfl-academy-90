# Asset Specifications for L-52-government-economy: Government's Role in the Economy

**Scope:** 3 interactive/printable HTML assets for a 55-minute class
**Pattern:** Matches L-1 through L-45 Oklahoma scope (3-5 files per chapter)

## Asset List (3 files total)

### 1. Government Services Cost-Benefit Analyzer (PRIMARY SKILL BUILDER)
**File:** `Government_Services_Analyzer.html`
**Purpose:** Evaluate government services and their impact on personal finance
**Use:** Day 2 primary activity (15-20 minutes)
**Type:** Interactive web application

**Features:**
- Interactive tool with state-specific data where applicable
- Real-time calculations and visual feedback
- Scenario-based learning
- Printable results

---

### 2. Supporting Worksheet
**File:** `Supporting_Worksheet.html`
**Purpose:** Guided practice activity
**Use:** Chapter worksheet (10-12 minutes)
**Type:** Interactive + printable worksheet

---

### 3. Reference Sheet
**File:** `Reference_Sheet.html`
**Purpose:** Quick reference for key concepts
**Use:** Reference material
**Type:** Printable 1-page reference

## State Variables Used

No state-specific variables required (Tier 3 universal content)

## 55-Minute Class Flow

**Day 1 (Foundation):**
- 0-5 min: Distribute Reference Sheet
- 5-40 min: Direct instruction
- 40-50 min: Discussion and examples
- 50-55 min: Preview Day 2 tools

**Additional Activities:**
- 0-10 min: Review and setup
- 10-30 min: Government Services Cost-Benefit Analyzer (pairs)
- 30-45 min: Supporting activities (individual)
- 45-53 min: Reflection
- 53-55 min: Wrap-up

## Implementation Notes

- All HTML files must be self-contained (no external CDN dependencies)
- Print-friendly CSS required
- File sizes under 500KB
- Mobile-responsive design
- Meets WCAG 2.1 AA accessibility standards
- PFL Academy color scheme (indigo #6366f1, purple #8b5cf6)

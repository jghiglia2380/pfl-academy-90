# Asset Specifications for L-47: Introduction to Investment Types

**Scope:** 4 interactive/printable HTML assets for a 55-minute class
**Pattern:** Matches L-1 through L-45 Oklahoma scope (3-5 files per chapter)

## Asset List (4 files total)

### 1. Investment Type Comparison Tool (PRIMARY INTERACTIVE TOOL)
**File:** `Investment_Type_Comparison_Tool.html`
**Purpose:** Interactive tool to compare stocks, bonds, mutual funds, and ETFs
**Use:** Chapter interactive activity (15-20 minutes)
**Type:** Interactive web application

**Features:**
- Side-by-side comparison of 4 investment types
- Key characteristics for each:
  - Risk level (visual indicator)
  - Historical average return
  - Liquidity (how quickly can sell)
  - Minimum investment
  - Typical fees/costs
- Scenario builder: "I have $X to invest for Y years"
- Recommendation engine based on goals and risk tolerance
- Real examples of each type (ticker symbols, fund names)
- Printable comparison chart

---

### 2. Fee Impact Calculator
**File:** `Fee_Impact_Calculator.html`
**Purpose:** Demonstrate how fees compound to reduce investment returns over time
**Use:** Chapter worksheet (10-12 minutes)
**Type:** Interactive calculator

**Features:**
- Initial investment amount input
- Monthly contribution input
- Time horizon (years)
- Fee/expense ratio comparison (0.05%, 0.5%, 1.5%)
- Visual chart showing growth with different fee levels
- "Fees cost you $X over Y years" calculation
- Comparison: Low-cost index fund vs. high-cost actively managed fund

---

### 3. Investment Risk Tolerance Quiz
**File:** `Investment_Risk_Tolerance_Quiz.html`
**Purpose:** Help students assess personal risk tolerance
**Use:** Chapter worksheet (8-10 minutes)
**Type:** Interactive quiz + worksheet

**Sections:**
- 10-question quiz on risk tolerance
- Scoring: Conservative / Moderate / Aggressive
- Recommended investment types for each profile
- Asset allocation suggestions (% stocks vs. bonds)
- "What this means for you" summary

---

### 4. Investment Types Reference Sheet
**File:** `Investment_Types_Reference_Sheet.html`
**Purpose:** Quick reference for all investment types covered
**Use:** Reference material
**Type:** Printable 1-page reference

**Content:**
- **Stocks:**
  - Definition, risk/return, examples
  - When to use
- **Bonds:**
  - Definition, risk/return, examples
  - When to use
- **Mutual Funds:**
  - Definition, risk/return, fee structure
  - Active vs. passive management
- **ETFs (Exchange-Traded Funds):**
  - Definition, advantages, fee structure
  - How they differ from mutual funds
- Key terms glossary
- Investment selection decision tree

---

## State Variables Used

No state-specific variables required (Tier 3 universal content)

## 55-Minute Class Flow

**Chapter Resource Usage Suggestions:**
- 0-5 min: Distribute Investment Types Reference Sheet
- 5-25 min: Direct instruction on stocks, bonds, funds, ETFs
- 25-45 min: Investment Type Comparison Tool (interactive activity - pairs)
- 45-55 min: Debrief and wrap-up

**Additional Activities:**
- 0-10 min: Review and setup
- 10-27 min: Fee Impact Calculator (individual)
- 27-45 min: Risk Tolerance Quiz (reflection)
- 45-55 min: Discussion and wrap-up

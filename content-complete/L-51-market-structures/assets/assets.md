# Asset Specifications for L-51-market-structures: Market Structures and Consumer Choice

**Scope:** 4 interactive/printable HTML assets for a 55-minute class
**Pattern:** Matches L-1 through L-45 Oklahoma scope (3-5 files per chapter)

## Asset List (4 files total)

### 1. Market Structure Identifier (PRIMARY INTERACTIVE TOOL)
**File:** `Market_Structure_Identifier.html`
**Purpose:** Identify market structures and develop consumer strategies
**Use:** Chapter interactive activity (15-20 minutes)
**Type:** Interactive web application

**Features:**
- Interactive tool with state-specific data where applicable
- Real-time calculations and visual feedback
- Scenario-based learning
- Printable results

---

### 2. Supporting Worksheet

**Use:** Chapter worksheet (10-12 minutes)
**Type:** Interactive + printable worksheet

### 3. Reference Sheet

**Purpose:** Quick reference for key concepts
**Use:** Reference material

## State Variables Used (Where Applicable)

STATE_UTILITY_PROVIDERS, STATE_TELECOM_PROVIDERS

## 55-Minute Class Flow

**Chapter Resource Usage Suggestions:**
- 0-5 min: Distribute Reference Sheet
- 5-25 min: Direct instruction
- 25-45 min: Market Structure Identifier (interactive activity - pairs)
- 45-55 min: Debrief and wrap-up

**Additional Activities:**
- 0-10 min: Review and setup
- 10-35 min: Supporting activities (individual)
- 35-50 min: Reflection and discussion
- 50-55 min: Wrap-up

- All HTML files must be self-contained (no external CDN dependencies)
- Print-friendly CSS required
- File sizes under 500KB
- Mobile-responsive design
- Meets WCAG 2.1 AA accessibility standards

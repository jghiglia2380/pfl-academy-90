# Asset Specifications for L-48: Economic Systems and Resource Allocation

**Scope:** 3 interactive/printable HTML assets for a 55-minute class
**Pattern:** Matches L-1 through L-45 Oklahoma scope (3-5 files per chapter)

## Asset List (3 files total)

### 1. Economic Systems Comparison Tool (PRIMARY INTERACTIVE TOOL)
**File:** `Economic_Systems_Comparison_Tool.html`
**Purpose:** Interactive comparison of capitalism, socialism, and mixed economies
**Use:** Chapter interactive activity (15-20 minutes)
**Type:** Interactive web application

**Features:**
- Side-by-side comparison of 3 economic systems
- Key characteristics:
  - Resource ownership (private vs. public)
  - Price determination (market vs. planned)
  - Economic freedom index
  - GDP per capita ranges
  - Pros and cons for consumers
- Real country examples for each system
- Personal career impact analysis: "In which system would I thrive?"
- Printable comparison chart

---

### 2. Property Rights Impact Simulator
**File:** `Property_Rights_Impact_Simulator.html`
**Purpose:** Show how property rights affect investment and economic decisions
**Use:** Chapter worksheet (10-12 minutes)
**Type:** Interactive scenario tool

**Features:**
- 3 scenarios (starting a business, buying property, investing)
- Property rights slider: Weak → Moderate → Strong
- Probability-based outcomes for each scenario
- Expected value calculations
- Visual showing how strong property rights encourage investment
- Real-world examples from different countries

---

### 3. Economic Systems Reference Sheet
**File:** `Economic_Systems_Reference_Sheet.html`
**Purpose:** Quick reference for economic systems characteristics
**Use:** Reference material
**Type:** Printable 1-page reference

**Content:**
- Capitalism: Definition, key features, examples
- Socialism: Definition, key features, examples
- Mixed Economy: Definition, key features, examples (most countries)
- Property rights importance
- Decision-making comparison (market vs. government)
- Historical examples (East/West Germany, North/South Korea)
- Personal finance implications in each system

---

## State Variables Used

No state-specific variables required (Tier 3 universal content)

## 55-Minute Class Flow

**Chapter Resource Usage Suggestions:**
- 0-5 min: Distribute Economic Systems Reference Sheet
- 5-25 min: Direct instruction on economic systems, property rights
- 25-45 min: Economic Systems Comparison Tool (interactive activity - pairs)
- 45-55 min: Debrief and wrap-up

**Additional Activities:**
- 0-10 min: Review and setup
- 10-35 min: Property Rights Impact Simulator (individual)
- 35-50 min: Reflection and discussion
- 50-55 min: Wrap-up

## Implementation Notes

- All HTML files must be self-contained (no external CDN dependencies)
- Print-friendly CSS required
- File sizes under 500KB
- Mobile-responsive design
- Meets WCAG 2.1 AA accessibility standards
- PFL Academy color scheme (indigo #6366f1, purple #8b5cf6)
